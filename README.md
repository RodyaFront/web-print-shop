# Фігулярня

Сайт майстерні: `/figurky` (фігурки під ключ; 18+ - опція у формі), `/detali` (друк деталей), окремі форми замовлення.

## Стек

- Nuxt 4
- Локальне JSON-сховище в `data/` (без окремої БД)

## Стан сайту (`data/`)

Усе робоче наповнення лежить у `data/` і **потребує бекапу**:

| Шлях | Зміст |
| --- | --- |
| `data/orders/` | Заявки та завантажені файли клієнтів |
| `data/catalog/` | Каталог фігурок (`figurky.json`) |
| `data/settings/` | Ставки `/detali` (`pricing.json`) |
| `data/media/` | Обкладинки та кадри обертання з адмінки |

При першому запуску каталог і ціни сідають з дефолтів у код. Далі зміни лише через `/admin`.

## Запуск

1. Скопіюйте `.env.example` у `.env` і задайте `NUXT_ADMIN_PASSWORD` та `NUXT_SESSION_SECRET`.
2. Встановіть залежності: `npm install`
3. Запустіть: `npm run dev`

Адмінка: `/admin` (пароль з `.env`) - заявки, каталог, ціни деталей.
