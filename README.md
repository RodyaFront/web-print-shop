# Фігулярня

Сайт майстерні: `/figurky` (фігурки під ключ; 18+ - опція у формі), `/detali` (друк деталей), окремі форми замовлення.

## Стек

- Nuxt 4
- Локальне сховище заявок у `data/orders/`

## Запуск

1. Скопіюйте `.env.example` у `.env` і задайте `NUXT_ADMIN_PASSWORD` та `NUXT_SESSION_SECRET`.
2. Встановіть залежності: `npm install`
3. Запустіть: `npm run dev`

Адмінка: `/admin` (пароль з `.env`).

## Умови продажу

- Лише Україна
- Доставка поштою
- Оплата накладеним платежем
- Публічний сайт українською
