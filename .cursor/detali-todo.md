# `/detali` - чеклист для замовника

Спільний список. Редагуємо разом: `[ ]` → `[x]`, можна міняти пункти й додавати нотатки.

Джерело пріоритетів: що потрібно потенційному замовнику 3D-друку деталей (не внутрішня кухня).

## Must-have

- [x] **Які задачі беремо** - сітка (4 в ряд): фото + title + опис; зараз AI-моки в `public/mock/detali/`
  - замінити на свої фото після приходу принтера (по кадру на категорію)
- [x] **Обмеження друку** - макс. розмір, мін. товщина стінок / деталізація (без моделі принтера)
  - стінки/дріб позначені як орієнтири; можна замінити на ваші робочі цифри в `shared/print-services.ts`
- [x] **Матеріали через властивості** - стандартний / інженерний / ливарний з «для чого» і рисами
- [x] **Ціна** - як рахується + таблиця «від» + мін. замовлення
- [x] **Файли й процес** - STL/OBJ + 4 кроки + орієнтир строку («назвемо після моделі»)
- [x] **Доставка / оплата** - Україна, пошта, накладений / картка; онлайн-оплати немає; лінк на `/delivery`

## Вторинно

- [ ] **Приклади робіт** / фото якості
  - немає асетів для деталей (лише `public/mock/figurky`); не ставити порожню «галерею»
- [x] **CTA + форма** `/detali/zamovyty` - intro узгоджено (файли, мін. замовлення, оцінка після моделі)
  - опційно пізніше: поле «тип задачі» / підказка матеріалу у формі

## Нотатки

- Публічно: ліміти деталі й властивості матеріалу, не інвентар принтерів.
- Копірайт: `copy-uk.mdc` (аудиторія - замовник).
- Дані: `shared/print-services.ts`. Сторінка: `app/pages/detali/index.vue`.
- Мін. замовлення - лише в блоці цін, не в hero.
- Meta description: сервіс + гео + типи задач + матеріал/файл + ціна від + доставка (без мін. замовлення в сніпеті).
